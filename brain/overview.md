# Deskpost Overview

Shared support inbox across projects: threaded conversations, internal notes, canned responses, live viewer presence, auto-replies, embeddable widget, email in and out.

**Goals**: real Rust backend for the existing UI; free email (plain SMTP out, IMAP/webhook in); local file attachments; tested end to end. Details in `docs/PLAN.md`.

**Non-goals**: paid email/storage services, SaaS billing, mobile apps.
