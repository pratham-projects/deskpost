# Product

## Register
brand

## Users
Small teams and agencies who want a support inbox they own instead of renting one per seat: a founder handling support for two products, an agency answering for several clients, an ops person who already runs Postgres and a mail server. They arrive from GitHub, a search or a recommendation, on a laptop, wanting proof it is real and cheap to run before they install.

## Product Purpose
Deskpost is the site name for SendDesk (repository `sendesk`, binary `api`): an open-source (AGPL-3.0-only) multi-tenant support-ticket inbox. Shared queue across projects, threaded conversations, internal notes, canned responses, attachments, live viewer presence, an embeddable customer widget, and email in (IMAP poll or signed webhook) and out (SMTP). Rust API, Next.js UI, one Postgres, no paid services.

## Brand Personality
Plain, dependable, a little dry. A well-kept shared mailbox: nothing lost, every thread in order. Confident through specifics, not adjectives.

## Anti-references
Generic SaaS gradients, glassmorphism, stock "customer happiness" imagery, fake logos, invented customer counts or response-time promises, hero-metric tiles, icon-card grids, chat-bubble clip art.

## Design Principles
1. Prove with the mechanism: the hero shows mail becoming a thread and a ticket landing in the queue.
2. Real facts only: GitHub counts, measured numbers with their hardware, or nothing. Never an invented claim.
3. Install in one copy-paste, docs one click away, and say plainly what is pre-release.
4. Dark only, warm ink. One saturated amber field per page (the install band) carries the brand color at scale.

## Accessibility & Inclusion
WCAG AA contrast, visible focus, keyboard-operable tabs and docs nav, `prefers-reduced-motion` freezes the ASCII canvas on a finished frame, canvas is aria-hidden with all copy in real text.

## Brand commitments
Fonts: Geist Pixel Square (display), Satoshi (body), Geist Mono (code). Icons: Hugeicons. Dark theme only. ASCII canvas hero background (`inbox` scene). The rename to Deskpost is site-only; docs state the real repo and binary names.
